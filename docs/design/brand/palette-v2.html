Palettes and contrast

Every ratio below is computed live from the tokens on this page (WCAG 2.x relative luminance). Text pairs need 4.5:1; orange marks, focus rings, the selection bar, the logo ring and chart colours need 3:1. The same check runs in the build script, which refuses to write this file if any pair fails.
