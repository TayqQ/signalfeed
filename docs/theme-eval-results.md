## With the LLM check (D47)

The full method: a tag whose best similarity is at least τ_high joins that theme, below τ_low it starts a new one, and in between gpt-5.6-luna chooses among up to 3 candidate themes or none. Band tags with no verdict fall back to τ = 0.76.

- **Verdicts:** gpt-5.6-luna, prompt `theme-check-v2`, recorded 2026-11-11 from `text-embedding-3-small-512-market-v1.json`: 369 verdicts. 369 questions in 27 calls, 0 of them with no usable answer, 32138 input and 29838 output tokens, $0.0390.
- **Best by rule:** τ_low 0.72, τ_high 0.88. F1 0.662 (precision 0.930, recall 0.515). The rule takes the best F1 and prefers the higher precision within 0.01 of it.
- **Default in code (`DEFAULT_THEME_BANDS`):** τ_low 0.72, τ_high 0.88. F1 0.662 (below target)
